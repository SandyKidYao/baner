# 体验设计规范

视觉的唯一来源是 [`src/theme/tokens.css`](../../src/theme/tokens.css):颜色、字号、间距、圆角都从那里取,本文不重复色值,只说明规则和用途。

## 品牌性格

- 是:极客、锋利、高效。不是:温吞、装饰、傻瓜化。
- 语气:能用符号就不用字;非用字不可时用短句,以名词或动词开头,不寒暄、不道歉。
  - 正例:`⚿ 本机未配置主密钥  ⚙ →`
  - 反例:「哎呀,您还没有设置密钥哦~点击这里去设置吧!」

## UX 原则

1. **键盘优先**:每个桌面操作都有快捷键,状态栏常驻显示最常用的几个。
2. **符号代替文字**:文字只在符号说不清时出现(错误原因、首次配置)。每个符号都有悬停提示,写出全名和快捷键。
3. **不打断书写**:保存、同步、冲突都不弹窗,状态只体现在同步符号上。
4. **不可逆的操作再按一次**:删除 tab、更换主密钥时,按钮原地变成「再按一次确认」,不弹对话框。
5. **手机上主操作放在拇指区**:新建块固定在右下角。

## 界面结构

只有一个主界面,其余都是它上面的状态或面板。

**Islands 布局**:窗口底色是靛蓝(`--color-rail`),上面浮着圆角的「岛」(`--color-surface`,圆角 `--radius-island`);岛与岛、岛与窗口边缘之间留 `--island-gap` 的缝。

| 区域 / 状态 | 规则 |
|---|---|
| 页面岛 | 顶部是 tab 条,下面是当前 tab 的连续分块页 |
| tab 条 | 单字方块 + 名称(最宽 200,超出省略),横排,多了横向滚动,切换时自动露出当前 tab;末尾是 +(新 tab)。当前 tab:浅底 + 2px 主色下划线,单字方块为琥珀色。单击切换;长按约 350ms 浮起后左右拖动排序;双击或聚焦后按 F2 原地改名;右键菜单:改名、左移 / 右移、同步、加密、删除 |
| 页头右侧 | 当前 tab 的状态(⚿ 加密、⟳ 同步 / ○ 不同步)和「所见 / 源码」切换 |
| 状态栏 | 横跨窗口底部,在底色上:左边快捷键提示,右边同步符号与 ⚙。窗口窄时放不下的提示整项隐藏 |
| 同步与加密 | ⚙ 打开,在页面岛右侧另开一个 340px 的岛。从上到下:GitHub 登录(验证码大字居中,右侧是复制按钮)与仓库选择 → 本机主密钥 → 每个 tab 的同步和加密开关 → 版本(版本号、检查更新;有新版本时「更新并重启」) |
| 有新版本 | 启动后和每隔几小时在后台检查。有新版本时 ⚙ 右上角出现琥珀色小圆点(手机上在抽屉的「同步与加密」后面),不弹窗;后台检查失败不提示,手动检查才显示「已是最新」或错误原因 |
| 关闭窗口 | macOS 上关闭按钮和 ⌘W 隐藏应用(同 ⌘H),应用留在 Dock;点 Dock 图标恢复,⌘Q 退出 |
| 首次打开 | 一个空块加状态栏的快捷键提示,没有欢迎页 |
| 本机未配主密钥 | 只在这台设备没配置主密钥时,加密 tab 显示锁和「⚙ →」入口;配置过的设备进出加密 tab 没有任何提示 |
| 手机布局(宽度 < 600) | 顶栏(≡、tab 名、同步、所见/源码)在底色上,页面是一整块岛;≡ 打开左侧圆角岛抽屉(tab 用上移 / 下移排序);右下角 + 新建文本块 |

弹出层(右键菜单、同步错误原因)是浮起的小岛,允许一层柔和阴影(`--shadow-pop`);其余地方不用阴影。

## 块

- 块按顺序编号,序号在最左侧。图块与文本块一起编号,序号下加淡色 ◇。
- **当前块**(文本块、渲染好的代码块、编辑中的图块):撑满岛宽的直角浅底(`--color-current`),左右不留缝;序号变成琥珀色小方块(`--color-rail-accent` 底、`--color-rail-on-accent` 字),与 tab 条上当前 tab 的单字方块一致。
- **冲突块**:警告色淡底;序号是警告色描边的方块并加「!」(如 `03!`),形状上与当前块的实心方块不同。git 冲突标记原样保留,由用户手动清理。

## Markdown 文本块

文件始终是纯 `.md`。

- **所见**(默认):光标不在的行隐藏标记并渲染(标题、粗体、斜体、删除线、行内代码、链接、列表、待办、引用、代码块);光标所在行显示淡色标记(`--color-faint`);列表标记挂在悬挂缩进里,文字不左右跳;待办的方框可以直接点。
- **源码**:原样显示,只给标记上色;每块显示从 1 开始的行号,与块的 `.md` 文件行号一致,在序号右侧单独一列。
- 切换:页头右侧(Aa / #)、手机顶栏、⌘E。是本机全局偏好,不进仓库。
- 列表里回车续上前缀(有序 +1、待办变未完成),空项回车结束列表。
- **Tab** 在编辑器里缩进:无选区时插入两个空格,在列表项里整项缩进一级;有选区时缩进选中各行;⇧Tab 反缩进;分隔行永远不动。Esc 后 2 秒内按 Tab 可以离开编辑器。

**代码块**

- 所见模式下光标不在代码块里时,渲染成块内的圆角盒子:头部是语言名(没写为「代码」)和复制按钮,下面是高亮后的代码。点代码,光标落到对应的行列,代码块切回原样以便编辑。上下方向键遇到渲染好的代码块时,光标进到它的最后一行或第一行。
- 原样显示时每行带代码底色(`--color-code-bg`),开头一行末尾有复制按钮。
- 复制按钮是两个叠放方框的图标,成功后短暂变成 ✓;只复制代码本身,不含 ```。
- 高亮按 ``` 后的语言名按需加载,颜色是 `--color-code-*`。
- 没闭合的顶层 ``` 在块分隔处结束,不吞掉后面的块。
- **⇧⌥F 格式化**当前代码块(按物理键位判断),光标留在原来的行;结果在开头 ``` 那一行末尾显示 2.5 秒:「✓ 已格式化」「✕ 第 N 行语法错误」「✕ 不支持格式化 xx」。支持 JS/TS/JSON/CSS/SCSS/Less/HTML/Vue/Markdown/YAML/GraphQL(Prettier)与 SQL(sql-formatter),格式化器按需加载。在代码块外按下不做任何事。

## 图块

- ⌘D 或 ◇ 在当前块下方插入;点击已有图块进入编辑。
- 编辑时就在原位:没有边框盒子,画布透明,透出当前块底色并叠一层淡点阵;与预览同一原点、100% 缩放,图不重新居中。
- Excalidraw 自带的工具条、菜单、缩放、帮助全部隐藏(画布小时它会切到手机布局),由下面两样代替:
  - **块工具条**:9 个绘图工具(V R D O A L P T E)| 删除(垃圾桶图标,悬停变危险色)、✓。
  - **属性小岛**:选中图形时出现在右上角(描边、背景、线宽、线型、风格)。
- 底边可拖动调高度。✓ 或 ⌘↵ 退出后显示为 SVG 预览图。✕ 只用于关闭或取消。

## 快捷键

状态栏按常用程度显示:⌘↵ 新块、⌘D ◇ 图块、⌘A 选块、⌘E 所见/源码、⌘T 新 tab、⌘1–9 切换 tab、⇧⌥F 格式化代码、⌘, 同步与加密。

## 交互状态

| 状态 | 处理方式 |
|---|---|
| 空 | 只有一个空块,加状态栏的快捷键提示 |
| 加载 | 启动即可用,不显示启动加载;同步进行中时同步符号旋转(「减少动效」时改为静止符号加一个点) |
| 错误 | 同步符号变成危险色的 ✕;点击后在它上方弹出一行原因,如 `✕ GitHub 授权失效,请重新登录  ⟳ 重试`。本地数据始终保留,不回滚 |
| 冲突 | 同步符号带 ⚠;冲突块的样式见「块」 |
| 成功 | 同步符号恢复为普通的 ⟳,不弹任何提示 |

## 排版

- 全部使用等宽字体,系统字体栈,中文回落到系统黑体,不加载外部字体。
- 字号阶梯 11 / 12 / 13 / 15 / 18;桌面正文 13,手机正文 15。
- 行高:正文 1.6,界面元素 1.3。字重只用 400 和 700。
- 间距是 4 的倍数(4 / 8 / 12 / 16 / 24 / 32)。

## 配色

- 第一版只有一个主题「极客 · 锋利 · 高效」:靛蓝底色、白色岛、琥珀色强调。亮色、暗色各一套,默认跟随系统,`[data-mode]` 可手动覆盖。
- token 按 `[data-theme]` 作用域组织,为以后加主题预留。
- 底色在亮暗两种模式下都是深靛色,所以底色上的强调色单独用 `--color-rail-accent`;普通的 `--color-primary` 在亮色底上对比度不够。
- `--color-warning` 和 `--color-primary` 是同一个琥珀色,冲突靠 ⚠ 和「!」的形状区分,不靠颜色。
- 改色值时守对比度门槛:正文与次要文字对背景 ≥ 4.5:1;控件描边、状态色、图标对背景 ≥ 3:1。

## 组件

- **符号按钮**:34×34(手机 44×44),图标 18px,线宽 2;必须带 `aria-label` 和悬停提示(全名 + 快捷键)。
- **双态开关**:按 tab 开关同步和加密。关闭时只有描边,打开时主色填充、反白显示符号。
- **输入框**:1px 描边,焦点时 2px 主色外框;token 和主密钥默认掩码显示,旁边的 ◉ 可以临时显示原文。
- **不使用**:toast、模态对话框、欢迎页、引导浮层。

## 可访问性

- 目标 WCAG 2.2 AA。
- 所有操作都能用键盘完成;焦点可见,统一为 2px 主色外框。
- 每个符号都有 `aria-label`;状态不只靠颜色区分。
- 遵循系统的「减少动效」设置。
- 手机上的点击目标不小于 44×44。
